🔍 High-Impact Exploratory Defects Surfaced

Beyond automation, ReleaseGuard's exploratory audit revealed critical pre-launch vulnerabilities in the target application:

DEF-SEC-01: Broken Object-Level Authorization (BOLA / IDOR)

PATCH /users/:userId and GET /transactions/:transactionId authenticate users but never verify object ownership. Any logged-in user can overwrite another user's profile or inspect private transactions across tenants.

DEF-01: Non-Atomic Financial Ledger Mutations

A single peer-to-peer transfer runs 4 separate, un-bracketed database writes. A server restart mid-sequence permanently desynchronizes sender and receiver balance records.
