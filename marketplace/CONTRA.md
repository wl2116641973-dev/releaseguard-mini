# Contra Service Specification

## Service Title
**SaaS Pre-Launch QA & Playwright Critical-Flow Automation**

---

## Service Description
I help early-stage startup founders and development teams ship code without fear. I test your web application through the lens of a paying customer, catch regressions before your users do, and deliver a clean, maintainable Playwright automated test suite ready for CI.

---

## Deliverables
- **Exploratory Functional Audit**: Comprehensive walkthrough of signup, onboarding, primary CRUD, and transaction workflows.
- **Actionable Defect Reports**: Markdown defect logs with reproducible steps, environment details, and visual evidence.
- **Playwright Regression Suite**: TypeScript tests built using resilient user-facing locators (`getByRole`, `getByLabel`), and web-first assertions designed to prevent flaky timeouts.
- **Native Test Reports & Trace Artifacts**: Playwright HTML report and interactive traces captured on test failures.
- **Continuous Integration Pipeline**: Drop-in GitHub Actions workflow for pull-request testing.

---

## Pricing Tiers (Launch Strategy)
- **Starter QA Audit**: $49 (3 flows, manual QA, defect report, 2 days)
- **Core Automation Suite**: $89 (4 flows, 6 Playwright tests, HTML report, 3 days)
- **Complete LaunchGuard + CI**: $149 (5 flows, 8–10 Playwright tests, GitHub Actions CI, handoff, 4 days)
