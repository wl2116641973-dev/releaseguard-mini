## Gig Description

**Are you about to launch your SaaS, but terrified that signups, payments, or core workflows will silently break for your first paying users?**

I provide pre-launch functional QA and automated Playwright regression suites specifically tailored for modern Web & SaaS applications. 

### What You Get:
1. **Critical User Journey Verification**: I test the flows that directly impact revenue and activation (Auth, Payments, Onboarding, CRUD, Settings).
2. **Defect Reports That Developers Love**: No vague summaries. You get exact steps to reproduce, expected vs. actual behavior, console error logs, and screenshots.
3. **Rock-Solid Playwright Automation (Standard & Premium)**: Clean TypeScript code using user-facing locators (getByRole, getByLabel) and web-first assertions. No fragile selectors, no flaky sleep timeouts.
4. **CI/CD Integration (Premium)**: Drop-in GitHub Actions workflow running Chromium tests on every pull request, with automatic HTML reports and failure traces.

## Scope Boundaries & Guardrails
To guarantee quality and deterministic turnarounds, the following guardrails apply:
- **Environment**: Staging, preview, or local sandbox only. (No production credentials or live credit card charges).
- **Platform**: Modern Desktop Web applications (Chromium).
- **Exclusions**: Feature software development, security penetration scanning, DDoS load testing, and native mobile iOS/Android apps.
